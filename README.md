# 🌸 Flower Shop Website

A web-based Flower Shop Website developed using PHP, MySQL, HTML and CSS.

## 📌 Project Description

The Flower Shop Website is an online web application that allows users to
browse flower products, manage their shopping cart and place orders.

The system also provides an admin section for managing products and orders.

## 🛠 Technologies Used

- MySQL

- XAMPP

- Flower Product Display
- Product Management
- Shopping Cart
- Checkout System
- Order Management
- Admin Login
- Database Connectivity
- User-friendly Interface

## 💻 Requirements

- XAMPP
- PHP
- MySQL
- Web Browser

## 🚀 How to Run the Project

1. Install XAMPP.
2. Copy the project folder into:

   `C:\xampp\htdocs\`

3. Start **Apache** and **MySQL** from XAMPP.
4. Create/import the `flower_db` database using phpMyAdmin.
5. Open the following URL in your browser:

   `http://localhost/flowerproject/`
